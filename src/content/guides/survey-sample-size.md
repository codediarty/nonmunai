논문 표본 수 계산은 사용할 분석 방법, 기대하는 효과크기, 유의수준(α), 검정력(1-β)을 정한 뒤 G\*Power로 진행합니다. 가장 흔한 기본 설정인 중간 효과크기, α = .05, 검정력 .80을 적용하면 예측변수 3개인 다중회귀분석은 77명, 독립표본 t검정은 집단당 64명이 필요합니다. 계산값은 최소 기준이므로 탈락과 불성실 응답을 고려해 여유 있게 모집해야 합니다.

## 표본 수를 결정하는 네 가지 요소

검정력 분석은 실제로 효과가 있을 때 그것을 통계적으로 찾아낼 확률을 충분히 확보하려면 몇 명이 필요한지 계산하는 과정입니다. 다음 네 가지 값이 정해지면 표본 수가 결정됩니다.

- 효과크기: 찾아내려는 효과의 크기입니다. 효과가 작을수록 더 많은 표본이 필요합니다.
- 유의수준(α): 효과가 없는데 있다고 잘못 판단할 위험의 허용치로, 보통 .05를 씁니다.
- 검정력(1-β): 실제 효과를 찾아낼 확률로, Cohen이 제안한 .80을 관례적으로 많이 씁니다.
- 분석 방법과 모형: 같은 효과크기라도 예측변수 수나 집단 수가 늘어나면 필요한 표본이 커집니다.

효과크기를 어떻게 정하느냐가 결과를 가장 크게 좌우합니다. 유사한 선행연구가 보고한 효과크기가 있다면 그 값을 근거로 쓰고, 근거가 없다면 Cohen(1988)이 제시한 관례적 기준을 사용합니다.

| 분석 | 효과크기 지표 | 작은 효과 | 중간 효과 | 큰 효과 |
|---|---|---|---|---|
| t검정 | d | 0.20 | 0.50 | 0.80 |
| 분산분석 | f | 0.10 | 0.25 | 0.40 |
| 다중회귀분석 | f² | 0.02 | 0.15 | 0.35 |
| 상관분석 | r | .10 | .30 | .50 |

## 분석 방법별 필요 표본 수

아래 값은 G\*Power에서 α = .05, 검정력 .80, 중간 효과크기를 넣어 계산한 결과입니다.

| 분석 방법 | G\*Power 설정 | 필요 표본 수 |
|---|---|---|
| 다중회귀분석, 예측변수 1개 | Linear multiple regression: Fixed model, R² deviation from zero, f² = 0.15 | 55명 |
| 다중회귀분석, 예측변수 2개 | 위와 같음 | 68명 |
| 다중회귀분석, 예측변수 3개 | 위와 같음 | 77명 |
| 다중회귀분석, 예측변수 4개 | 위와 같음 | 85명 |
| 다중회귀분석, 예측변수 5개 | 위와 같음 | 92명 |
| 독립표본 t검정 | Means: Difference between two independent means, d = 0.50, 양측검정 | 집단당 64명(전체 128명) |
| 대응표본 t검정 | Means: Difference between two dependent means (matched pairs), dz = 0.50, 양측검정 | 34명 |
| 일원분산분석, 3집단 | ANOVA: Fixed effects, omnibus, one-way, f = 0.25 | 전체 159명(집단당 53명) |
| 상관분석 | Correlation: Bivariate normal model, r = .30, 양측검정 | 84명 |

예측변수 수에 통제변수도 포함된다는 점을 놓치기 쉽습니다. 성별, 연령 같은 통제변수 2개와 주요 독립변수 3개를 함께 투입한다면 예측변수는 5개로 계산해야 합니다. 조절효과 분석처럼 상호작용항을 넣는 모형이라면 상호작용항도 예측변수 수에 포함합니다.

## G\*Power로 직접 계산하는 순서

다중회귀분석에서 예측변수가 3개인 경우를 예로 들면 다음과 같습니다.

1. Test family에서 F tests를 선택합니다.
2. Statistical test에서 Linear multiple regression: Fixed model, R² deviation from zero를 선택합니다.
3. Type of power analysis는 A priori를 선택합니다.
4. Effect size f²에 0.15, α err prob에 0.05, Power에 0.80, Number of predictors에 3을 입력합니다.
5. Calculate를 누르면 Total sample size가 77로 나옵니다.

t검정은 Test family를 t tests로 바꾸고, 분산분석은 F tests에서 ANOVA 항목을 고르면 같은 방식으로 계산할 수 있습니다. 계산 화면을 저장하거나 입력값을 기록해 두면 연구방법을 쓸 때 편리합니다.

## 계산값보다 더 모아야 하는 이유

G\*Power가 알려 주는 값은 분석에 실제로 투입되는 최소 표본 수입니다. 설문 연구에서는 응답을 중간에 멈추거나 불성실하게 응답한 자료를 제외해야 하는 경우가 많으므로, 예상 탈락률을 고려해 계산값보다 넉넉하게 모집합니다. 탈락률은 연구 대상과 수집 방식에 따라 달라지므로 비슷한 선행연구를 참고해 정하고 그 근거를 적습니다.

분석 방법에 따라 별도의 경험적 기준이 쓰이기도 합니다.

- 다중회귀분석: Green(1991)은 모형 전체를 검정할 때 50 + 8m(m은 예측변수 수) 이상을 제안했습니다.
- 요인분석: 문항 수의 5배에서 10배 이상을 권하는 경험적 기준이 자주 인용됩니다.
- 구조방정식모형: 모형이 복잡할수록 큰 표본이 필요하며, 200명 이상을 권장하는 문헌이 많습니다.

여러 분석을 함께 한다면 가장 큰 표본이 필요한 분석을 기준으로 정합니다.

## 연구방법에 근거를 쓰는 법

표본 수 산출 근거는 다음과 같이 씁니다. "본 연구의 표본 크기는 G\*Power 3.1을 이용하여 다중회귀분석을 기준으로 중간 효과크기(f² = 0.15), 유의수준 .05, 검정력 .80, 예측변수 5개를 적용하여 산출하였으며, 최소 92명이 필요한 것으로 나타났다. 탈락률을 고려하여 ○○명을 모집하였다."

## 기술 조사라면 다른 공식을 씁니다

변수 간 관계를 검정하는 것이 아니라 모집단의 비율을 추정하는 조사라면 검정력 분석 대신 허용 오차로 표본 수를 정합니다. 신뢰수준 95%, 허용 오차 ±5%, 응답 비율을 50%로 가정하면 약 385명이 필요합니다. 모집단 규모가 작다면 유한모집단 보정을 적용해 필요한 수를 줄일 수 있습니다.

설문지를 아직 구성하는 중이라면 [설문지 만드는 법](/guide/how-to-make-questionnaire/)을, 수집 후 분석 계획은 [SPSS 통계분석 방법](/guide/spss-analysis-guide/)을 함께 참고하세요.

분석 방법과 변수 수만 넣으면 바로 계산되는 [표본 수 계산기](/tools/sample-size/)로 내 연구의 최소 표본을 먼저 확인해 보세요. 수집 계획까지 점검이 필요하다면 [설문조사](/survey/) 지원 페이지가 도움이 됩니다.
