## 하루 한 번 처리 순서

1. 운영자 화면 '오늘의 작업'을 엽니다. 결제 확인, 견적 작성, 작업 순서, 새 메시지가 한 화면에 모입니다.
2. **결제 확인**: 아임웹(skkc.co.kr) 주문 내역이나 통장 내역에서 주문자 이름·연락처·금액을 논문AI 주문과 맞춰 보고 '확인'을 누릅니다. 고객은 주문서와 같은 이름·연락처로 결제하도록 안내받고, 주문번호를 따로 적지 않습니다. 고객이 '결제를 마쳤어요'를 누르지 않은 주문도 '결제 전' 목록에서 같은 방법으로 찾아 확인합니다. 내역이 없으면 '내역 없음'을 누르면 고객에게 안내가 갑니다.
3. **견적 작성**: 견적형 주문(응답자 모집, 구조방정식 등)은 금액과 기간을 정해 '견적 확정'을 누릅니다. 고객에게 결제 안내 메일이 갑니다.
4. **작업**: 작업 순서에서 '지시문 복사'를 누르면 연구 설계, 가설, 목차, 분석 계획, 고객 자료 목록, 점검표가 정리된 작업지시문이 복사됩니다. 고객 이름과 연락처는 들어가지 않습니다. 주문 상세의 'AI 작업 프롬프트' 탭에는 장별로 바로 붙여 넣을 수 있는 프롬프트가 있습니다.
5. 실제로 작업을 시작하면 '착수 기록'을 눌러 둡니다. 환불 기준(작업 착수 전 전액 환불)을 판단할 때 씁니다. 결과물을 올리면 자동으로 기록됩니다.
6. **전달**: 결과물을 끌어 놓아 올린 뒤 '전달 완료 처리'를 누르면 고객 화면에 내려받기가 열리고 메일이 갑니다. 20MB가 넘는 파일은 Drive 주문 폴더의 '2_결과물'에 넣고 'Drive에서 가져오기'를 누릅니다.
7. **메시지**: 답하지 않은 고객 메시지는 주문 상세 '기록·메시지' 탭에서 답합니다. 자주 쓰는 안내 문구 단추가 있습니다.

## 고객 화면에 보이는 단계

| 단계 | 언제 바뀌나 |
|---|---|
| 견적 확인 중 | 견적형 주문을 제출했을 때 |
| 결제 전(운영자 화면에서는 결제 대기) | 주문서를 제출했거나 견적을 확정했을 때 |
| 결제 확인 중 | 무통장입금 알림을 받았을 때(확인 전) |
| 작성·분석 진행 | 결제가 확인되거나, 성균관컨설팅 결제 완료 알림을 받았을 때. 예상 전달일과 작업 순서가 함께 표시 |
| 자료 보완 필요 | 운영자가 자료를 요청했을 때 |
| 품질 검토 | 운영자가 바꿀 때 |
| 전달 완료 | 운영자가 전달 완료로 바꿀 때 |

자료 확인, 작업 준비 단계는 주문서 제출 때 시스템이 필수 자료와 연구 설계안을 자동으로 확인·생성한 것으로 표시됩니다.

## 논문 주문서(한 화면)

- **주소**: /paper/new/ 한 화면에서 끝납니다. 받는 것은 ① 관심 주제나 키워드(편하게 적은 말, 예: '간호사 이직이랑 번아웃 관련해서'), ② 전공(직접 입력, 비워도 됨), ③ 논문 종류와 분량, ④ 양식, ⑤ 이름·휴대전화·이메일뿐입니다. 홈 프롬프트에서 넘어오면 적은 문장에서 논문 종류·쪽수·전공·키워드를 읽어 미리 채웁니다.
- **제목은 고객이 정하지 않습니다**: 주문 기록의 주제 구분이 'free'(관심 주제)로 남고, 작업지시문 맨 앞에 '■ 주제 다듬기' 안내가 들어갑니다. 연구진이 선행연구가 충분하고 검증 가능한 주제로 제목을 확정합니다. 고객 화면과 메일에는 '관심 주제'로 표시됩니다.
- **양식**: '일반적인 논문 양식으로 해주세요'가 기본입니다. '학교 양식이 따로 있어요'를 고르면 파일을 올릴 수 있고, 파일 없이 내면 요청 사항에 '학교 양식은 나중에 따로 보낼 예정'이 남습니다.
- **더 맡길 것(접힘)**: 심사 발표 PPT, 우선 처리, 영문 작성, 양식 상세 적용, 추가 수정, 결과물 형식, 희망 전달일, 참고 자료, 요청 사항은 접힌 칸 안에 있어 필요한 사람만 엽니다.
- **원고 첨삭·교수님 피드백 반영**: 같은 화면 위쪽 탭에서 고르고 원고를 올리면 분량이 자동으로 계산됩니다. 피드백 반영은 받은 피드백을 파일이나 글로 남깁니다.
- **주문 조회 비밀번호**: 따로 받지 않고 휴대전화 뒤 4자리로 정합니다. 고객이 다른 기기에서 조회할 때 주문번호와 휴대전화 뒤 4자리를 넣습니다.
- **동의**: 필수 동의 체크는 없습니다. '주문서를 내면 이용약관, 개인정보 처리방침, 환불 규정이 적용됩니다'라는 안내와 각 문서 링크를 보여 주고, 할인·새 서비스 소식 받기만 선택 체크입니다. 주문 기록에는 필수 동의(개인정보 수집·이용, 연구윤리 안내, 청약철회 제한 안내)가 제출 시각으로 남습니다.
- **미리보기**: 오른쪽(모바일은 주제 칸 아래)에 고객이 적은 주제로 서론 첫 문단이 써지고, 나머지는 모자이크로 가려지며 '나머지 N쪽은 결제 후 완성됩니다'가 뜹니다. 미리보기 문장은 홍보용 화면이며 실제 원고는 연구진이 씁니다.
- **예전 단계별 주문서**: /paper/new/?detail=1에 그대로 있습니다. 설문조사·통계분석 주문서는 단계별 방식 그대로이고, 제출하면 똑같이 결제로 바로 이어집니다.

예상 전달일은 하루 처리 가능 건수(설정)와 쉬는 날을 반영해 계산합니다.

## 결제 연결

- **아임웹 논문AI 상품(49개)**: skkc.co.kr 관리자 > 상품 > 카테고리 '논문AI'에 본 상품 37개(소논문 8쪽, 석사 80쪽·박사 130쪽 묶음 상품 포함), 옵션 6개(심사 발표 PPT 제작, 영문 논문 작성 10쪽 단위, 심화 분석, 양식 상세 적용, 추가 수정, 우선 처리), 추가 분량 6개(단가별)가 있습니다. 상품 번호와 링크는 tools/imweb/links.json에 정리되어 있고, 운영 시트 '설정'의 skkcProducts에 같은 내용(JSON)이 들어 있습니다. 결제 화면은 주문 금액 줄마다 맞는 상품과 수량을 장바구니 목록으로 보여 줍니다(예: 석사 전체 구성·초고 완성 1개 + 추가 분량 2개 + 영문 논문 작성 8개).
- **묶음 상품(석사 80쪽 #148, 박사 130쪽 #149)**: 가장 많이 찾는 분량은 상품 하나로 결제합니다. 석사 80쪽 주문은 '본 상품 + 추가 분량 2개' 대신 '석사학위논문 80쪽 전체 구성·초고 완성(197,000원)' 하나만 담으면 되고, 박사 130쪽도 같습니다(328,000원). 결제 화면은 본 상품과 추가 분량을 더한 금액이 묶음 상품 가격과 같을 때만 묶음 상품으로 바꾸므로, 석사·박사 전체 작성 가격을 바꾸면 가격표의 P-MASTER-FULL-80, P-DOCTOR-FULL-130 줄과 아임웹 묶음 상품 가격도 같이 맞춰 주세요. 금액이 다르면 자동으로 원래의 두 줄 결제로 돌아갑니다.
- **주문서를 내면 바로 결제**: 결제할 아임웹 상품이 하나면(묶음 상품 포함) '성균관컨설팅 안전결제로 연결하고 있습니다' 화면이 2초쯤 보인 뒤 그 상품 페이지가 같은 창에서 열립니다. 결제 대기 화면을 거치지 않습니다. 연결 화면에는 주문번호, 상품과 금액, 운영사 안내, '결제 페이지 바로 열기'와 '나중에 결제할게요'가 있습니다. 결제 상품이 여러 개(추가 분량·옵션)이면 결제 화면에 장바구니 목록이 나옵니다. 토스페이먼츠를 켜면 연결 화면 없이 결제 화면의 결제창을 씁니다.
- **결제 화면 안내**: '성균관컨설팅 안전결제' 칸에 운영사 안내(논문AI는 성균관컨설팅이 운영, 결제·영수증은 성균관컨설팅 이름), 결제할 상품과 금액, 'OOO원 결제하기' 버튼, '결제를 마쳤어요' 버튼이 나옵니다. 주문번호를 붙여 넣으라는 안내는 없고, 결제할 때 주문서와 같은 이름·연락처를 적도록 안내합니다. 아임웹 상품 설명에도 '논문AI(nonmunai.kr)는 성균관컨설팅이 운영하는 논문 전문 서비스'라는 문장과 nonmunai.kr 링크가 들어 있어, 고객이 두 사이트를 같은 곳으로 알아봅니다.
- **상품을 고치거나 새로 만들 때**: 가격을 바꾸면 운영 시트 '가격표'와 아임웹 상품 가격을 같이 바꿔 주세요. 상품을 새로 만들면 설정의 skkcProducts에 "상품코드":"https://skkc.co.kr/shop_view/?idx=번호"를 더합니다. 기본 가격표의 이름·포함 문구가 바뀌었을 때는 Apps Script 편집기에서 syncCatalogText를 실행하면 가격·결제 링크는 그대로 두고 문구만 맞추고, 새 기본 상품은 뒤에 더해집니다.
- **상품 이미지·상세 다시 만들기**: node tools/imweb-products.mjs [출력 폴더]를 실행하면 표지 이미지, 상세 설명 HTML, 상품 목록(products.json), 결제 뒤 안내 이미지가 다시 만들어집니다. 상세 설명의 진행 순서는 '주문서 작성 → 이 상품으로 결제(주문서와 같은 이름·연락처) → 결제 확인과 작업 시작(메일 안내) → 완성본 메일 전달'이고, 논문 상품의 '논문AI가 다른 점'은 참고문헌 100% 실존 검증을 맨 앞에 둡니다.
- **성균관컨설팅 결제**: 기본 결제 수단입니다. 주문 금액과 정확히 같은 아임웹 상품 링크가 있으면 그 상품을 엽니다. 가격표의 '결제 링크' 칸이나 설정의 '금액별 결제 링크'에 넣습니다.
- **금액 단위 결제 상품**: 아임웹에 1,000원짜리 '논문AI 주문 결제' 상품을 숨김으로 만들고 설정의 '금액 단위 결제 상품 링크'에 넣으면, 금액이 맞는 상품이 없을 때 고객에게 '수량 428개(428,000원)'처럼 안내합니다.
- **결제 링크가 없을 때**: 위 두 가지가 모두 없고 '결제 페이지' 설정도 비어 있으면, 고객에게 상담 채널(채널톡)에 주문번호를 남기면 이 금액의 결제 링크를 보내 준다고 안내합니다. 이때는 상담 채널에서 결제 링크를 보내 주세요.
- **무통장입금**: 설정에서 켜고 은행·계좌·예금주를 넣으면 결제 화면에 나옵니다.
- **카드·간편결제(토스페이먼츠)**: 토스페이먼츠 클라이언트 키와 시크릿 키를 설정에 넣고 켜면 결제창이 붙습니다. 승인은 서버에서 금액을 다시 확인한 뒤 처리합니다.

## 가격 바꾸기

운영자 화면 '가격표'에서 가격, 납기, 추가 분량 단가를 고치고 저장하면 신청 화면과 서버 결제 금액에 바로 반영됩니다. 이미 접수된 주문 금액은 바뀌지 않습니다.

## 알림

- 새 주문, 결제 완료 알림, 견적 요청, 자료 제출, 수정 요청, 고객 문의는 contact@skkc.co.kr로 메일이 옵니다.
- 휴대폰 푸시를 받으려면 ntfy 앱에서 토픽을 하나 정해 구독하고, 설정 '휴대폰 푸시 알림 토픽'에 같은 이름을 넣습니다.
- 메일 발송 한도(하루 100통)에 가까워지면 메일은 대기열에 쌓였다가 매시간 다시 보냅니다.

## 자료 보관과 삭제

- 올린 자료와 결과물은 전달 완료 후 90일이 지나면 자동으로 영구 삭제됩니다.
- 제출하지 않은 주문서는 3일 뒤 개인정보까지 지우고, 결제하지 않은 주문은 30일 뒤 취소하고 자료를 지웁니다.
- 고객이 '자료 삭제 요청'을 누르면 결제 전·전달 후 주문은 바로 삭제되고, 작업 중인 주문은 알림이 옵니다. 운영자 화면 '자료 영구 삭제'로 처리합니다.
- 거래 기록(주문번호, 결제 내역)은 전자상거래법에 따라 5년 보관합니다.

## 사이트 고치기와 배포

저장소 main에 올리면 GitHub Actions가 테스트, 빌드, 배포, 검색엔진 알림(IndexNow)까지 2분 안에 끝냅니다. Claude가 고칠 때는 '논문AI 배포 묶음' 아티팩트로 소스 묶음을 올리고, Actions가 풀어서 반영합니다. 서버 코드를 바꾼 경우에는 Apps Script 편집기에 새 Code.gs를 넣고 '배포 관리 → 수정 → 새 버전'으로 같은 주소를 유지한 채 갱신합니다.

## 홈 화면과 가격

- **첫 화면**: "관심 주제와 전공만 편하게 적으세요" 안내와 오른쪽 작성 화면이 있습니다. 작성 화면이 화면에 들어오면 프롬프트 칸에 예시 문장('간호학과 석사인데, 간호사 이직이랑 번아웃 관련해서 논문 완성해 주세요')이 실제 한글 입력처럼 쳐지고(src/js/ui/hangul-typing.js), 'AI가 읽은 내용' 칩(석사학위논문·간호학·#키워드)이 붙은 뒤, 참고문헌 실존 검증 → 목차 → 서론 본문과 인용 순서로 써지다가 이어지는 부분(연구 목적, 제2장 이론적 배경)이 모자이크로 가려지고 '나머지 78쪽은 결제 후 완성됩니다' 자물쇠 안내가 뜹니다. 방문자가 프롬프트 칸을 누르면 연출이 바로 멈춥니다. 예시 제목은 "간호사의 번아웃이 이직의도에 미치는 영향: 회복탄력성의 매개효과"이고, 참고문헌 4편(Bae 2022, Bakker 외 2023, Cooper 외 2020, Shah 외 2021)은 모두 최근 실존 문헌으로 Crossref에서 저자·연도·권호·쪽·DOI를 확인했습니다. 예시를 바꿀 때도 실제로 확인한 문헌만 넣어 주세요(src/content/pages/home.mjs의 REFS, DEMO_PROMPT, DEMO_TITLE).
- **내 프롬프트로 써 보기**: 방문자가 자기 주제를 적고 보내면 주문서(/paper/new/?prompt=...)가 열리고, 거기서 그 주제로 미리보기가 써지다가 모자이크로 가려집니다(src/js/ui/paper-preview.js, src/js/core/preview.js). 미리보기 인용 표시는 저자를 흐리게 가린 칩이며 실제 문헌 목록은 작업 때 검증합니다.

## 검색 노출 관리

- **Google**: Search Console(skkc.office@gmail.com으로 로그인)에서 nonmunai.kr 속성을 엽니다. 사이트맵(https://nonmunai.kr/sitemap.xml)이 제출되어 있고, '페이지' 보고서에서 색인된 페이지 수를, '실적'에서 검색어별 노출·클릭을 봅니다.
- **네이버**: 서치어드바이저(searchadvisor.naver.com)에 nonmunai.kr을 등록했습니다. 소유 확인은 두 방식을 함께 걸어 두었습니다. site.config.json의 verification.naver(HTML 태그, 모든 페이지 head에 들어감)와 verification.naverFile(확인 파일, 사이트 맨 위 naver….html로 만들어짐)입니다. 둘 다 지우면 인증이 풀립니다. 사이트맵(https://nonmunai.kr/sitemap.xml)과 RSS(https://nonmunai.kr/rss.xml)는 요청 메뉴의 사이트맵 제출, RSS 제출에서 넣습니다.
- **다음**: 웹마스터도구(webmaster.daum.net)에 nonmunai.kr이 등록되어 있습니다. 로그인은 사이트 주소와 직접 정한 PIN으로 합니다. 소유 확인 코드는 site.config.json의 verification.daum에 있고 robots.txt 맨 아래에 자동으로 붙습니다(지우면 인증이 풀립니다). 사이트맵, RSS, 주요 페이지 수집 요청을 해 두었습니다.
- **빙·네이버 자동 알림**: 배포할 때마다 IndexNow로 바뀐 주소를 빙(api.indexnow.org)과 네이버(searchadvisor.naver.com/indexnow)에 보냅니다. GitHub Actions 배포 기록의 '검색엔진 색인 알림' 단계에서 결과(200)를 볼 수 있습니다.
- **AI 검색(ChatGPT, Claude, Perplexity 등)**: robots.txt에서 AI 검색 봇을 허용하고, 사이트 소개와 서비스·가격 요약을 /llms.txt, /llms-full.txt로 제공합니다.
- 새 가이드 글은 content/guides에 추가하면 사이트맵, RSS, llms.txt에 자동으로 들어가고 배포 때 IndexNow로 알려집니다.
