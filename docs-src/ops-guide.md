## 하루 한 번 처리 순서

1. 운영자 화면 '오늘의 작업'을 엽니다. 결제 확인, 견적 작성, 작업 순서, 새 메시지가 한 화면에 모입니다.
2. **결제 확인**: 아임웹(skkc.co.kr) 주문 내역이나 통장 내역에서 주문자 이름·연락처·금액을 논문AI 주문과 맞춰 보고 '확인'을 누릅니다. 고객은 주문서와 같은 이름·연락처로 결제하도록 안내받고, 주문번호를 따로 적지 않습니다. 고객이 '결제를 마쳤어요'를 누르지 않은 주문도 '결제 전' 목록에서 같은 방법으로 찾아 확인합니다. 내역이 없으면 '내역 없음'을 누르면 고객에게 안내가 갑니다.
3. **견적 작성**: 견적형 주문(응답자 모집, 구조방정식 등)은 금액과 기간을 정해 '견적 확정'을 누릅니다. 고객에게 결제 안내 메일이 갑니다.
4. **작업**: 작업 순서에서 '지시문 복사'를 누르면 연구 설계, 가설, 목차, 분석 계획, 고객 자료 목록, 점검표가 정리된 작업지시문이 복사됩니다. 고객 이름과 연락처는 들어가지 않습니다. 주문 상세의 'AI 작업 프롬프트' 탭에는 장별로 바로 붙여 넣을 수 있는 프롬프트가 있습니다.
5. 실제로 작업을 시작하면 '착수 기록'을 눌러 둡니다. 이용약관상 결제가 확인되면 바로 작업이 시작되므로(제14조) 청약철회 제한의 근거 기록이 됩니다. 결과물을 올리면 자동으로 기록됩니다. 환불은 이용약관 제5장 기준입니다(결제 전 취소 무료, 결제 후 결과물 발송 전 취소는 결제 금액의 20% 환불, 발송 후에는 환불 없이 수정으로 대응, 회사 귀책은 제26조).
6. **전달**: 결과물을 끌어 놓아 올린 뒤 '전달 완료 처리'를 누르면 고객 화면에 내려받기가 열리고 메일이 갑니다. 20MB가 넘는 파일은 Drive 주문 폴더의 '2_결과물'에 넣고 'Drive에서 가져오기'를 누릅니다.
7. **메시지**: 답하지 않은 고객 메시지는 주문 상세 '기록·메시지' 탭에서 답합니다. 자주 쓰는 안내 문구 단추가 있습니다.

## 고객 화면에 보이는 단계

| 단계 | 언제 바뀌나 |
|---|---|
| 견적 확인 중 | 견적형 주문을 제출했을 때 |
| 결제 전(운영자 화면에서는 결제 대기) | 주문서를 제출했거나 견적을 확정했을 때 |
| 결제 확인 중 | 무통장입금 알림을 받았을 때(확인 전) |
| 작성·분석 진행 | 결제가 확인되거나, 성균관컨설팅 결제 완료 알림을 받았을 때. 예상 전달일과 작업 순서가 함께 표시 |
| 자료 보완 필요 | 운영자가 자료를 요청했을 때 |
| 박사 검수(서버·관리 기록의 상태 이름은 '품질 검토') | 운영자가 바꿀 때 |
| 전달 완료 | 운영자가 전달 완료로 바꿀 때 |

자료 확인, 작업 준비 단계는 주문서 제출 때 시스템이 필수 자료와 연구 설계안을 자동으로 확인·생성한 것으로 표시됩니다.

## 논문 주문서(한 화면)

- **주소**: /paper/new/ 한 화면에서 끝납니다. 받는 것은 ① 관심 주제나 키워드(편하게 적은 말, 예: '간호사 이직이랑 번아웃 관련해서'), ② 전공(직접 입력), ③ 논문 종류(소논문 15 Page, 학사 졸업논문 30 Page, 학술지 투고논문 20 Page, 석사학위논문 80 Page, 박사학위논문 130 Page), ④ 양식뿐입니다. 바로 결제가 켜져 있으면(아래 '바로 결제') 이름·연락처·이메일은 주문서에서 받지 않고 성균관컨설팅 결제 화면에서 받습니다. 홈 프롬프트에서 넘어오면 적은 문장에서 논문 종류·분량·전공·키워드를 읽어 미리 채우고, 홈의 예시 문장을 그대로 들고 오면 칸을 비워 둡니다(예시는 예시일 뿐이라 '나의 전공 분야를 입력하세요' 같은 안내만 보입니다).
- **제목은 고객이 정하지 않습니다**: 주문 기록의 주제 구분이 'free'(관심 주제)로 남고, 작업지시문 맨 앞에 '■ 주제 다듬기' 안내가 들어갑니다. 연구진이 선행연구가 충분하고 검증 가능한 주제로 제목을 확정합니다. 고객 화면과 메일에는 '관심 주제'로 표시됩니다.
- **양식**: '일반적인 논문 양식으로 해주세요'가 기본입니다. '학교 양식이 따로 있어요'를 고르면 파일을 올릴 수 있고, 파일 없이 내면 요청 사항에 '학교 양식은 나중에 따로 보낼 예정'이 남습니다.
- **더 알려 주실 것(접힘)**: 연구 방법, 결과물 형식, 희망 전달일, 요청 사항은 접힌 칸 안에 있어 필요한 사람만 엽니다. 바로 결제가 켜져 있으면 유료 옵션(심사 발표 PPT, 우선 처리, 영문 작성, 양식 상세 적용, 추가 수정)과 파일 첨부는 주문서에 나오지 않습니다(결제 상품이 하나여야 바로 결제되기 때문). 학교 양식·참고 자료는 결제 후 주문 페이지에서 올리도록 안내합니다.
- **원고 첨삭·교수님 피드백 반영**: 같은 화면 위쪽 탭에서 고르고 원고를 올리면 분량이 자동으로 계산됩니다. 피드백 반영은 받은 피드백을 파일이나 글로 남깁니다.
- **주문 조회 비밀번호**: 따로 받지 않고 휴대전화 뒤 4자리로 정합니다. 고객이 다른 기기에서 조회할 때 주문번호와 휴대전화 뒤 4자리를 넣습니다.
- **동의**: 필수 동의 체크는 없습니다. 제출 버튼 아래에 '의뢰하면 이용약관, 개인정보 처리방침, 환불 규정에 동의한 것으로 봐요. 나만을 위한 맞춤 제작이라 결제가 확인되면 바로 작업이 시작되고, 완성본 발송 전 취소는 결제 금액의 20%를 환불하며 발송 후에는 환불되지 않아요'라는 안내와 각 문서 링크를 보여 줍니다(할인·새 서비스 소식 받기 체크는 없앴습니다). 면책·환불 같은 방어 문구는 이용약관에 모으되, 이 한 줄은 전자상거래법상 청약철회 제한을 주장하려면 소비자가 결제 전에 쉽게 볼 수 있는 곳에 알려야 해서 남겨 두었습니다. 주문 기록에는 필수 동의(개인정보 수집·이용, 연구윤리 안내, 청약철회 제한 안내)가 제출 시각으로 남습니다.
- **미리보기**: 오른쪽(모바일은 주제 칸 아래)에 고객이 적은 주제로 서론 '연구의 필요성' 네 문단이 몇 글자씩 이어서 써지다가 마지막 문단 중간에서 끊기고, 나머지는 모자이크로 가려지며 '결제하시면 나머지 N Page를 완성해 드려요'가 뜹니다(src/js/core/preview.js의 buildPreview, src/js/ui/paper-preview.js). 아래쪽 '참고문헌 실존 검증' 줄에는 파란 인증 배지가 붙습니다. 미리보기 문장은 홍보용 화면이며 실제 원고는 연구진이 씁니다.
- **결제 금액 칸**: 정가(취소선), 붉은 '반값' 표시, '오픈 기념 반값', 'AI 집필 → 전공 박사 검수 → 메일 전달' 흐름, '박사 검수까지 영업일 N일 이내 · 오늘 결제하면 O월 O일까지 전달'이 나옵니다. 버튼은 'OO원 결제하고 의뢰하기'입니다.
- **예전 단계별 주문서**: /paper/new/?detail=1에 그대로 있습니다. 설문조사·통계분석 주문서는 단계별 방식 그대로이고, 제출하면 똑같이 결제로 바로 이어집니다.

예상 전달일은 하루 처리 가능 건수(설정)와 쉬는 날을 반영해 계산합니다.

## 결제 연결

- **바로 결제(연락처 없이 바로 결제 화면으로)**: 운영 시트 '설정'의 skkcProducts(JSON)에 `"_direct":"on"`이 들어 있으면 켜집니다(지금 켜져 있음). 고객이 주문서를 내면 '논문 의뢰 접수' 창에 작업 순서(주제 분석과 연구 설계 → 실존 문헌 검증과 AI 집필 → 전공 분야 박사 최종 검수 → 검수 완료본 메일 전달)가 1.6초쯤 보인 뒤, 성균관컨설팅 상품 페이지를 건너뛰고 아임웹 결제 화면(/shop_payment)이 바로 열립니다. 주문 내용(주제, 전공, 논문 종류, 금액)은 결제 주소의 nm 값에 담겨 갑니다. 끄려면 `"_direct":""`로 바꾸면 예전처럼 주문서에서 연락처를 받고 주문번호를 먼저 만든 뒤 결제로 넘어갑니다. 토스페이먼츠를 켜거나, 결제 상품이 둘 이상이면(옵션·추가 분량) 바로 결제는 쓰지 않습니다.
- **skkc.co.kr 공통 코드(푸터)**: 아임웹 관리자 > 환경 설정 > SEO·공통 코드의 '푸터 코드'에 논문AI 연결 코드(tools/imweb/skkc-connect.html, 기존 AIMarker 코드 아래)가 들어 있습니다. 하는 일: ① 상품 페이지에 nm 값이 있으면 화면을 가리고 바로 구매(결제 화면)로 넘김 ② 결제 화면 맨 위에 '석사학위논문 80 Page · 관심 주제 · 정가 취소선 · 오픈 기념 반값(50%가 아니면 '오픈 기념 NN% 할인') · 금액' 안내를 붙임 ③ 고객이 '결제하기'를 누르면 결제 화면에 적은 이름·연락처·이메일로 논문AI 주문을 등록(조회 비밀번호는 휴대전화 뒤 4자리) ④ 주문 완료 화면에서 '결제를 마쳤어요'(결제 확인 요청)를 자동으로 보내고 '진행 상황 보기' 링크를 보여 줌. 연결 코드를 고치면 같은 파일을 고친 뒤 푸터 코드 칸에 다시 붙여 넣어 주세요. 운영 API 주소가 바뀌면 파일 안의 API 주소도 바꿔야 합니다.
- **결제 확인**: 바로 결제 주문은 아임웹 주문 완료와 동시에 '결제 확인 요청' 상태로 들어옵니다. 아임웹 주문 내역에서 결제가 실제로 됐는지 보고 운영자 화면에서 '확인'을 누르면 작업이 시작됩니다.
- **아임웹 논문AI 상품**: skkc.co.kr 관리자 > 상품 > 카테고리 '논문AI'. 논문 완성 상품은 #147 소논문 15 Page(29,000원, 정가 59,000원), #111 학사 졸업논문 30 Page(59,000원, 정가 119,000원), #108 학술지 투고논문 20 Page(99,000원, 정가 199,000원), #100 석사학위논문 80 Page(99,000원, 정가 199,000원), #104 박사학위논문 130 Page(199,000원, 정가 399,000원)이고, 연구계획서는 #114 학사(29,000원, 정가 59,000원), #103 석사(69,000원, 정가 139,000원), #107 박사(99,000원, 정가 199,000원)입니다. 아임웹 '정가'(originalPrice)를 넣어 두어 상품·결제 화면에 정가 취소선과 오픈 기념 반값이 함께 보입니다. 예전 묶음 상품 #148·#149는 #100·#104와 같은 내용으로 맞춘 뒤 진열에서 숨겼고 주문서는 쓰지 않습니다(삭제하지 않았습니다). 상품 번호와 링크는 tools/imweb/links.json, 운영 시트 '설정'의 skkcProducts에 있습니다.

## 홈 화면과 가격

- **첫 화면**: 명조 제목 '관심 주제 한 줄로 논문을 완성합니다', 논문 종류 바로가기(석사논문 80 Page·박사논문 130 Page·학술지 논문 20 Page), 대표 가격(석사학위논문 80 Page 정가 199,000원 취소선 → 반값 → 99,000원, 오픈 기념), '논문 의뢰하기' 버튼, 오른쪽 작성 화면이 있습니다. 작성 화면 오른쪽 위에는 파란 인증 배지가 달린 '참고문헌 100% 실존 검증' 카드가 떠 있습니다. 작성 화면이 화면에 들어오면 예시 문장('경영학 석사인데, MZ세대 직장인 워라밸이랑 이직 관련해서 논문 완성해줘')이 실제 한글 입력처럼 쳐지고, 참고문헌 검증 → 목차를 거쳐 서론 '연구의 필요성' 네 문단이 AI가 쓰듯 몇 글자씩 이어서 써집니다. 인용 8곳이 나올 때마다 오른쪽 실존 확인 목록의 같은 문헌이 밝혀지고, 마지막 문단 중간('일-성장 균형 가운데')에서 끊기며 나머지는 모자이크로 가려지고 '결제하시면 나머지 78 Page를 완성해 드려요'가 뜹니다. 다 쓴 뒤에는 지면을 직접 굴려 서론 전체를 읽을 수 있습니다. 예시 제목은 'MZ세대 직장인의 워라밸이 이직의도에 미치는 영향'이고, 참고문헌 8편(Bakker 외 2023, Greenhaus 외 2003, Griffeth 외 2000, Haar 외 2014, Hom 외 2017, Kelliher 외 2019, Rudolph 외 2021, Twenge 외 2010)은 Crossref에서 저자·연도·제목·학술지·권호·쪽·DOI를 확인했고, 본문 문장은 각 문헌의 실제 내용과 맞게 썼습니다. 예시를 바꿀 때도 실제로 확인한 문헌만 넣어 주세요(src/content/pages/home.mjs의 REFS·NEED, src/js/core/preview.js의 DEMO_PROMPT·DEMO_TITLE).

## 검색 노출 관리

- **Google**: Search Console(skkc.office@gmail.com으로 로그인)에서 nonmunai.kr 속성을 엽니다. 사이트맵(https://nonmunai.kr/sitemap.xml)이 제출되어 있고, '페이지' 보고서에서 색인된 페이지 수를, '실적'에서 검색어별 노출·클릭을 봅니다.
- **네이버**: 서치어드바이저(searchadvisor.naver.com)에 nonmunai.kr을 등록했습니다. 소유 확인은 두 방식을 함께 걸어 두었습니다. site.config.json의 verification.naver(HTML 태그, 모든 페이지 head에 들어감)와 verification.naverFile(확인 파일, 사이트 맨 위 naver….html로 만들어짐)입니다. 둘 다 지우면 인증이 풀립니다. 사이트맵(https://nonmunai.kr/sitemap.xml)과 RSS(https://nonmunai.kr/rss.xml)는 요청 메뉴의 사이트맵 제출, RSS 제출에서 넣습니다.
- **다음**: 웹마스터도구(webmaster.daum.net)에 nonmunai.kr이 등록되어 있습니다. 로그인은 사이트 주소와 직접 정한 PIN으로 합니다. 소유 확인 코드는 site.config.json의 verification.daum에 있고 robots.txt 맨 아래에 자동으로 붙습니다(지우면 인증이 풀립니다). 사이트맵, RSS, 주요 페이지 수집 요청을 해 두었습니다.
- **빙·네이버 자동 알림**: 배포할 때마다 IndexNow로 바뀐 주소를 빙(api.indexnow.org)과 네이버(searchadvisor.naver.com/indexnow)에 보냅니다. GitHub Actions 배포 기록의 '검색엔진 색인 알림' 단계에서 결과(200)를 볼 수 있습니다.
- **AI 검색(ChatGPT, Claude, Perplexity 등)**: robots.txt에서 AI 검색 봇을 허용하고, 사이트 소개와 서비스·가격 요약을 /llms.txt, /llms-full.txt로 제공합니다.
- 새 가이드 글은 content/guides에 추가하면 사이트맵, RSS, llms.txt에 자동으로 들어가고 배포 때 IndexNow로 알려집니다.
